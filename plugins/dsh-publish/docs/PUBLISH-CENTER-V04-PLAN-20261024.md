> 项目: 老王工作台发布插件（dsh-publish）
> 日期: 2026-10-24
> 状态: 批次 0 已完成（接入验证见 [V04-BATCH0-VERIFICATION](V04-BATCH0-VERIFICATION-20261024.md)）；本方案按《审核与智能发布助手方案》全部修改要求重写，作为批次 1+ 实施依据
> 已删除: "内容工作台 = Park 打包"定位、40 字素材门槛、固定六标题候选、固定平台语气假设。Park 调研仅作人工发布环节的参考。

## 1. 定位

**一个插件内的智能发布助手**：接收已有内容 → 理解素材 → 推荐发布方式 → 生成平台版本 → 检查缺项 → 引导人完成发布并留下记录。**智能化的验收标准是减少重复输入和人工检查，而非增加表单与生成按钮。**

人机分工：AI 负责发布前准备；用户在平台完成最终发布。不恢复自动代发；旧自动引擎保留为独立实验能力（服务端真禁用，见 §6）。

## 2. 主流程（运行逻辑）

### 2.1 从已有内容开始

首页唯一主入口："这次要发什么？"

- 输入：粘贴成稿 / 选择 Markdown、TXT、**SRT 字幕**文件（经既有暂存接口进 DSH Host，Host 侧解析）/ 附加图片视频（只作附件，记录路径与大小）。
- 视频没有字幕且未接入转写时，界面如实显示"**尚未读取视频内容**"，允许补字幕或仅用现有文字继续；文件名与媒体类型不作为"已理解"的证据。
- 从 Obsidian 等创作产物进入时记录来源文件与读取时版本；只读用户本次选择的文件，不扫描知识库。
- 本插件不做选题、对标、拍摄、剪辑。

### 2.2 先理解，再推荐

- AI 先输出简短理解：这篇讲什么、面向谁、哪些事实已有依据（引用素材原句）。
- 然后给建议平台与形式及**理由**（规则判断管"平台支持什么"，AI 解释"内容适合什么"）；用户可增删，不强制五平台全生成。
- 素材缺事实时**只问影响当前结果的一项**（如"这里提到提升了效率，有具体例子吗？"），可跳过；跳过则生成不含该断言的版本。**禁止编造数据、经历、引用。** 无机械字数门槛。
- 不输出无数据依据的爆款概率或效果承诺。

### 2.3 为选定平台生成可用版本

每平台默认**一个推荐稿**，附"改了什么、为什么"；备选标题按需展开。按"平台×形式"生成字段：

| 形式 | 字段 |
|---|---|
| 视频描述 | 开头钩子、描述、话题、关联视频与封面状态 |
| 小红书图文 | 标题、正文、话题、图片顺序与缺图提示 |
| 公众号文章 | 标题、**独立摘要**、结构与正文、可复制排版版本、封面及配图状态 |
| X 标准短帖 | 完整短帖文本、媒体关联、加权字符数（不强塞标题字段） |

**定向修改**："只改小红书开头""公众号保留原文不扩写""三个平台都少点推销口吻"——执行前识别范围，结果先作候选；差异预览、接受、撤销；**用户手改过的字段永不被后台悄悄替换**（版本策略见 §5）。

首版可整理已有图片与封面状态，不生成封面/图片；转写、视觉理解为批次 3 可插拔能力，接入前如实标注支持范围。

### 2.4 AI 检查与规则检查各负其责

- **规则检查**（确定性）：字段长度（含 X 加权计数）、必需媒体、形式兼容、保存状态。
- **AI 检查**（建议性）：标题是否夸大、正文是否出现无来源数据、与素材是否一致（指出原句/字幕时间）；不包装成平台审核保证。
- 首页显示可执行缺项（"公众号还缺封面""X 超出字符上限""视频内容尚未读取"），每项可跳转字段或生成修改建议；硬限制不满足不能标"准备完成"，但仍可保存、编辑、复制。

### 2.5 人工发布与结果记录

- 准备完成的平台卡：字段级复制、媒体查看、打开平台后台（**入口白名单**；桌面经宿主能力开系统浏览器、Web 开新标签页，分别验证）。
- 复制只记复制，打开只记打开，**均不推断已发布**。
- 用户逐平台点"**标记已发**"（默认不勾，防误记）：确认所用版本，可补时间、作品链接、平台上的实际修改；可不填链接，界面注明"人工标记，未核验"。可"撤销标记"（只纠正本插件记录，不涉及平台作品）。
- 同一内容不同平台/批次分别记录；手动记录不复用自动引擎的 unknown 状态，也不声称平台结果已验证。

## 3. 页面与设置

插件内四区：**智能发布（默认首页）/ 草稿 / 发布记录 / 设置**。平台卡顺序沿用拖拽；首页优先显示本次要完成的事，不铺五张空表单。

设置（沿用 showSidebar / homeCards，新增项随批次 2 落地）：

| 设置 | 默认 | 行为 |
|---|---|---|
| 侧边栏入口 | 开（showSidebar） | 隐藏入口后设置页仍可进插件 |
| 默认打开页 | 智能发布 | 仅插件内首页 |
| 常用平台与顺序 | 沿用 homeCards | 推荐初值；本次取消不改长期偏好 |
| 默认发布形式 | 各平台分别保存 | 初值；AI 提示不适配，不静默替换 |
| 默认模型 | 跟随 DSH 路由 | 显示实际 provider/model；`ai.status` 缺模型/未登录给配置入口 |
| 个人风格资料 | 未选=当前素材 | 显示实际读取的资料与版本 |
| 平台规则 | 内置已核验版本 | 展示来源/日期/单位；未核实项只提示不硬拦 |
| 自动保存 | 开 | "保存中/已保存/保存失败"可见，失败可重试 |
| 草稿与附件位置 | DSH 数据目录 | 可查看、导出、检查缺失；不静默删稿 |
| 小红书数据读取 | 单独显式启用 | 未启用不自动查号读数 |
| 实验：自动发布 | 关 | 见 §6；与旧 publishingEnabled 语义分离 |

## 4. AI 集成（按批次 0 验证结论）

- 路由：`ctx.agentDefaultModel.currentSelection()`；调用：`ctx.llm.stream()`，文本增量 `text-delta`，取消经 `signal`，失败经 `finish{kind:'error'}` 结构化返回。
- **账号型 provider 边界**：`deepseek-account` 需 DSH 内账号登录（`ACCOUNT_SIGN_IN_REQUIRED` 实测）；ai.status 翻译为可操作提示；正式桌面可用性由批次 1 用户实机抽查。
- **生成依据自存**（DSH 不自动记录非 loop 调用）：每次生成任务记录素材版本、提示词、平台规则版本、provider/model、请求与结果（不含任何凭据）。
- E2E 用 mock provider 验控制流；不把 mock 成功写成真实成稿质量。

## 5. 数据设计（版本化保存）

| 对象 | 存储 | 要点 |
|---|---|---|
| 素材 | `<DSH_HOME>/publish/drafts/<id>/material.json` + 附件 | 粘贴文本或解析后的 SRT/MD；带内容哈希做版本 |
| 平台草稿 | 同目录 `platforms/<platform>.json` | 字段级区分 `ai 生成候选` / `用户编辑`（edited 标记，生成不得覆盖）；保存带预期修订号，服务端拒绝陈旧覆盖 |
| 生成任务 | `generations.jsonl`（追加） | 完整生成依据（§4）；分平台独立成功/失败/取消/重试 |
| 人工确认 | `manual-records.json` | 绑定确认时的快照；撤回只改标记；补链接不换快照 |
| 偏好 | DSH 设置（volatile） | 默认形式、平台顺序等 |
| 旧台账 | 只读保留 | 兼容展示，不迁移不改写 |

生成返回前用户已改稿 → 结果只作候选或标"已过期"，绝不覆盖。

## 6. 实验通道的服务端真禁用

- 新配置 `autoChannelEnabled`（默认 false），与旧 `publishingEnabled` 分离（旧开关语义不变）。
- 关闭时：页面不出现自动入口；**聊天工具 publish_prepare/publish_submit 服务端直接拒绝**（不只是隐藏）；已排队任务执行前复查开关，不开新引擎操作；模型侧工具声明不注册。
- 历史记录（含 unknown）任何状态下可查；已有外部提交不假定可撤回。

## 7. 平台规则表（`src/rules.ts`，规则与建议分离）

按"平台×形式×字段"定义，每条含：值、单位、校验方式、来源、核验日期、**硬拦/提示**级别。批次 1 先落小红书+公众号已核验项；X 计数按官方规则实现（URL 折算 23、加权 emoji、Unicode 规范化——优先引入 twitter-text，不可用则按文档实现并注明差异）；其余平台数字未经核实的只提示不硬拦，随核验记录补齐。

## 8. 批次与工期（批次 0 后按复用程度重估）

| 批次 | 范围 | 工期估算 |
|---|---|---|
| 1：智能最小闭环 | 文字/SRT 输入 → 理解与推荐（小红书+公众号）→ AI 适配生成（含独立摘要）→ 规则+AI 检查缺项 → 定向修改与改稿保护 → 自动保存 → 字段复制 + 打开后台 → 逐平台标记已发（版本快照）；mock provider E2E | 3–4 天（素材解析、版本化草稿与改稿保护是主要工作量） |
| 2：五平台与设置完整性 | 抖音/视频号/X（X 加权计数）；设置全表；实验通道服务端禁用与迁移告知；旧数据兼容 | 2–3 天 |
| 3：媒体理解增强 | 视频转写、图片理解、封面/配图（可插拔） | 接入后单估 |
| 4：复盘建议 | 手动记录关联数据、人工填数、下一次调整建议 | 1–2 天 |

验收标准逐条执行《审核与智能发布助手方案》第 8 节清单，不在本方案重复。
